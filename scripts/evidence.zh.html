标杆场景：证据等级

“模型任务”指真实模型调用工具完成流程；“框架验证”指确定性控制或协议验证；“设备 / UI 验证”不自动等于模型自主完成。

  • 找一家餐厅，再走到它门口。 读取真实商户信息，传入地图匹配门店，查看步行路线，再切回原商户页。 范围：模型任务通过 · 小米 12 / API 35。
  • 一个主题，跨应用看全。 两端检索同一主题，分别读取可见结果，保留来源归属与原应用搜索状态。 范围：模型任务通过 · 小米 12 / API 35。
  • 三个窗口，各自有序。 同时持有独立会话和显示空间；停止其中一个应用，另外两个仍可观察与操作。 范围：模型任务通过 · 小米 12 / API 35。
  • 需要时，接过控制权。 通过固定画布、小窗或原生任务接管应用，交还后恢复 Agent 控制，旧快照失效。 范围：框架验证通过 · 小米 10 / 12、API 37。
  • 从未知数值，找到唯一目标。 受控原生区域设备测试覆盖 2,099,200 个候选；支持扫描撤销、修改撤销与方案保存。 范围：设备 / UI 验证 · API 35 / 37 · 非全进程性能基准。
  • 一句指令，完成内存闭环。 本地模型通过 MCP 执行筛选撤销、冻结干扰恢复和模块锚点指针解析，并清理会话。 范围：模型任务通过 · 自有夹具 · 限定范围。
  • 网页与原生控件，都能操作。 完成文本输入、提交、开关、列表滚动与重组后的元素定位，连接两类界面交互。 范围：模型任务通过 · 自有测试应用。
  • 一个任务受阻，其余继续。 次应用未就绪时保留源应用会话与搜索状态，逐包归因并清理，不把失败扩散到整个任务。 范围：故障隔离任务通过 · 非 12306 业务通过。
  • 把 Android 能力接入你的工具。 外部客户端发现能力、读取界面与截图，执行点击、输入、滚动，并检查过期会话拒绝。 范围：协议 / 框架验证 · 按接入方式与环境记录。

内存修改与 Agent

小米 12 Pro / API 35 和 API 37 的自有夹具中，已有精确搜索、筛选、修改、读回和关闭会话记录。API 35 本地模型通过 MCP 的筛选撤销、HTTP 模块锚点指针、HTTP 冻结、修复后的 stdio 冻结任务通过。

受控原生区域的未知值扫描覆盖 2,099,200 个候选，验证尾部变化筛选与扫描撤销；这不是任意游戏全进程扫描基准。单级模块锚点解析不等于任意多级反向指针扫描。能力仅涉及容器内授权目标，不涉及服务器数值。

记录：2026-10-07-memory-agent-matrix；2026-10-08-memory-search-parity。

位置、VPN 与流量抓取

位置场景覆盖定位查询 / 回调、Wi-Fi、基站及部分 GNSS / NMEA 接口。网络连接状态、DNS 和 VPN 路径保持真实；位置模拟不是网络出口位置改变。VPN 路由由共享网络路径承载，不承诺每个虚拟应用独占 VPN 出口。

抓取是虚拟应用进程范围的流量观测，不是全设备 VPN 抓包。Android 13 / 15 真机与 API 36 AVD 已记录 DNS、HTTP/2、QUIC 样本和 HTTPS 请求成功；API 36 有 TLS 事件记录。协议事件不等于所有加密内容可解密，具体覆盖取决于目标协议和接入路径。
