内存修改与 Agent

小米 12 Pro / API 35 和 API 37 的自有夹具中，已有精确搜索、筛选、修改、读回和关闭会话记录。API 35 本地模型通过 MCP 的筛选撤销、HTTP 模块锚点指针、HTTP 冻结、修复后的 stdio 冻结任务通过。

受控原生区域的未知值扫描覆盖 2,099,200 个候选，验证尾部变化筛选与扫描撤销；这不是任意游戏全进程扫描基准。单级模块锚点解析不等于任意多级反向指针扫描。能力仅涉及容器内授权目标，不涉及服务器数值。

位置、VPN 与流量抓取

位置场景覆盖定位查询 / 回调、Wi-Fi、基站及部分 GNSS / NMEA 接口。网络连接状态、DNS 和 VPN 路径保持真实；位置模拟不是网络出口位置改变。VPN 路由由共享网络路径承载，不承诺每个虚拟应用独占 VPN 出口。

抓取是虚拟应用进程范围的流量观测，不是全设备 VPN 抓包。Android 13 / 15 真机与 API 36 AVD 已记录 DNS、HTTP/2、QUIC 样本和 HTTPS 请求成功；API 36 有 TLS 事件记录。协议事件不等于所有加密内容可解密，具体覆盖取决于目标协议和接入路径。
