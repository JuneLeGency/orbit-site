# Orbit website

Public, buildless marketing site for Orbit. Contact: miioflee@gmail.com.

## Preview

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

## Publish

GitHub Actions deploys only index.html, evidence.html, assets/, and .nojekyll from main to GitHub Pages. Set Pages source to GitHub Actions.

## Content policy

Historical evidence is summarized in evidence.html. Keep device / version / scope boundaries with claims. Do not publish internal logs, serial numbers, accounts, or raw diagnostic archives. The interactive workflow is explicitly a demonstration. TikTok SIM-free usage remains pending dedicated validation. Do not invent competitor benchmarks.

## Design

Responsive static HTML/CSS/JS. Canvas orbital illustration, reduced-motion support, workflow selector, email copy, application test summary, and nine playbooks. No analytics or backend. Optional Google Fonts with local fallback.
